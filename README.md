## Compiling and Running

The exercises use C++ and can be compiled with `g++` with C++11 support.

For a standalone exercise, run the following in a Linux terminal or WSL on Windows:

```bash
g++ -std=c++11 exercise.cc -o exercise
./exercise
```

Replace `exercise.cc` with the relevant filename. Exercises with multiple source files require those files to be compiled together.

Any included executables were built in the original development environment and may not run on your system; compile from source instead.
